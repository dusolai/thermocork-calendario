# Calendario de Redes Sociales — THERMOCORK

Planificacion trimestral de contenido para redes sociales de THERMOCORK.

- **90 publicaciones** distribuidas en 3 meses
- **85 imagenes reales** de obras
- **13 videos reales** de proyectos
- **Infografias generadas** con marca oficial
- **Sistema de comentarios** integrado para revision del departamento de diseno

## Uso del sistema de comentarios

Cada publicacion incluye una seccion de comentarios plegable. El departamento de diseno puede:

1. Abrir la seccion de comentarios de cualquier post
2. Escribir su nombre y el comentario
3. Los comentarios se guardan automaticamente en el navegador (localStorage)
4. Tambien hay una seccion de **Comentarios Generales** al final de la pagina para observaciones globales

> **Nota:** los comentarios se almacenan localmente en cada dispositivo/navegador. Si se abre en otro equipo, los comentarios no se transfieren automaticamente.

## Visualizacion en GitHub Pages

Este calendario puede publicarse como GitHub Pages para compartir facilmente con el equipo.
